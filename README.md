# DemoHero

DemoHero is a Mac-native recorder that captures the screen, camera, and voice together, then turns that take into a watchable product-demo video in minutes.

**[Visit the product page](https://demoheroapp.github.io/demohero/)**

## Support and feedback

Need help, found a bug, or have a feature request? [Open an issue](https://github.com/demoheroapp/demohero/issues/new) in this repository and we will get back to you.
